01. Decide what belongs in code¶

Level 1 · Revisited foundation

You will learn: Separate exact computation from uncertain interpretation.

A reported inventory count is a number; whether a note describes a bottleneck is a judgment. Do not spend a model call on addition, identifiers, permissions, or a rule already fully specified in code.

Reference: JEV limitations

03. Noul: one observable proposition¶

Level 1 · Revisited: atomic questions

You will learn: Read a probability of yes without treating it as ground truth.

Noul answers a yes/no proposition and returns noul in [0,1]. It does not carry the Choice/Score confidence field. This question concerns what the message explicitly says, not the actual outage state.

Reference: Noul primitive

04. Score: descriptive levels, not arbitrary numbers¶

Level 1 · Revisited: ordinal judgments

You will learn: Read an expected rubric position and preserve its distribution.

Use separate, concrete levels. A three-level Score is between 0 and 2, including fractional positions. It is not the probability that the ticket is serious, nor a measurement of the percentage of affected users.

07. Pre-parsed extraction: let code preserve the exact value¶

Level 2 · Revisited: bounded extraction

You will learn: Use JEV to identify a relevant span without asking it to invent a string.

A parser proposes candidates with offsets. JEV selects a candidate ID or NONE. Code returns the verbatim source slice. The email regular expression is intentionally small and not an exhaustive email validator.

Reference: Pre-parsed value extraction

def plc_scan(inputs, memory):
    boolean_inputs = ("start", "stop", "reset", "estop_ok", "guard_closed", "overload_ok")
    boolean_memory = ("run_latched", "fault_latched", "start_prev", "reset_prev")
    typed = (all(type(inputs.get(k)) is bool for k in boolean_inputs)
             and all(type(memory.get(k)) is bool for k in boolean_memory)
             and all(type(inputs.get(k)) is int and inputs[k] >= 0
                     for k in ("input_age_ms", "jam_elapsed_ms")))
    impossible = typed and memory["run_latched"] and memory["fault_latched"]
    unsafe = (not typed or impossible or not inputs["estop_ok"]
              or not inputs["guard_closed"] or not inputs["overload_ok"]
              or inputs["input_age_ms"] > 250 or inputs["jam_elapsed_ms"] >= 2000)
    run, fault = False, True
    if not unsafe:
        fault = memory["fault_latched"]
        reset_edge = inputs["reset"] and not memory["reset_prev"]
        start_edge = inputs["start"] and not memory["start_prev"]
        if fault and reset_edge and not inputs["start"]:
            fault = False  # Reset leaves STOP; a later start edge is required.
        elif not fault and not inputs["stop"]:
            run = memory["run_latched"] or start_edge
    result = {"run_latched": run, "fault_latched": fault,
              "start_prev": inputs.get("start") is True, "reset_prev": inputs.get("reset") is True}
    return {"output": "FAULT" if fault else "RUN" if run else "STOP", "motor_on": run, "memory": result}

from functools import lru_cache
TTT_LINES = ((0,1,2),(3,4,5),(6,7,8),(0,3,6),(1,4,7),(2,5,8),(0,4,8),(2,4,6))
def ttt_winner(board):
    return next((board[a] for a,b,c in TTT_LINES if board[a] != "." and board[a] == board[b] == board[c]), None)
def ttt_moves(board):
    return [] if ttt_winner(board) else [i for i,v in enumerate(board) if v == "."]
def ttt_apply(board, move, player):
    if player not in {"X", "O"} or move not in ttt_moves(board):
        raise ValueError("Illegal move or player.")
    expected = "X" if board.count("X") == board.count("O") else "O"
    if player != expected:
        raise ValueError("Wrong turn.")
    return board[:move] + (player,) + board[move+1:]
@lru_cache(None)
def ttt_value(board, player):
    winner = ttt_winner(board)
    if winner:
        return 1 if winner == player else -1
    if not ttt_moves(board):
        return 0
    opponent = "O" if player == "X" else "X"
    return max(-ttt_value(ttt_apply(board, m, player), opponent) for m in ttt_moves(board))

def c4_winner(board):
    for r in range(6):
        for c in range(7):
            if board[r][c] == ".":
                continue
            for dr,dc in ((0,1),(1,0),(1,1),(1,-1)):
                if all(0 <= r+dr*k < 6 and 0 <= c+dc*k < 7 and
                       board[r+dr*k][c+dc*k] == board[r][c] for k in range(4)):
                    return board[r][c]
    return None

def c4_legal(board):
    return [] if c4_winner(board) else [c for c in range(7) if board[0][c] == "."]

def c4_drop(board, col, player):
    if col not in c4_legal(board) or player not in {"X", "O"}:
        raise ValueError("Illegal column or player.")
    b = [list(row) for row in board]
    row = max(r for r in range(6) if b[r][col] == ".")
    b[row][col] = player
    return tuple(tuple(row) for row in b)

        elif not any(c4_winner(c4_drop(after, reply, opponent)) == opponent for reply in c4_legal(after)):
            safe.append(col)
    return immediate_wins or safe or all_moves

import random

def merge_line(line):
    values = [x for x in line if x]
    out, gained, i = [], 0, 0
    while i < len(values):
        if i+1 < len(values) and values[i] == values[i+1]:
            merged = values[i] * 2
            out.append(merged); gained += merged; i += 2
        else:
            out.append(values[i]); i += 1
    return out + [0] * (len(line)-len(out)), gained

def move_2048(board, direction):
    if direction not in {"left", "right", "up", "down"}:
        raise ValueError("Unknown direction.")
    vertical = direction in {"up", "down"}
    reverse = direction in {"right", "down"}
    lines = [list(row) for row in zip(*board)] if vertical else [list(row) for row in board]
    output, gained = [], 0
    for line in lines:
        merged, points = merge_line(line[::-1] if reverse else line)
        output.append(merged[::-1] if reverse else merged)
        gained += points
    result = tuple(tuple(row) for row in zip(*output)) if vertical else tuple(tuple(row) for row in output)
    return result, gained, result != tuple(tuple(row) for row in board)

    empty = [(r,c) for r in range(4) for c in range(4) if board[r][c] == 0]
    if not empty:

    b = [list(row) for row in board]; b[r][c] = 2 if tile_draw < 0.9 else 4
    return tuple(tuple(row) for row in b)

def checker_directions(piece):
    if piece.isupper():
        return ((1,1),(1,-1),(-1,1),(-1,-1))

    return ((dr,1),(dr,-1))

def checker_turns(board, side):
    if side not in {"r", "b"} or any(piece not in {"r","R","b","B"}
            or not (0 <= pos[0] < 8 and 0 <= pos[1] < 8 and sum(pos)%2 == 1)
            for pos,piece in board.items()):
        raise ValueError("Invalid teaching board.")
    captures = []
    def extend(b, pos, piece, path, taken):
        options = []
        for dr,dc in checker_directions(piece):
            middle = (pos[0]+dr,pos[1]+dc); landing = (pos[0]+2*dr,pos[1]+2*dc)
            if (0 <= landing[0] < 8 and 0 <= landing[1] < 8 and landing not in b
                and middle in b and b[middle].lower() != side):
                options.append((middle,landing))
        if not options and taken:
            captures.append({"path": path, "captured": taken, "promotes": False})
        for middle,landing in options:
            nxt = dict(b); del nxt[pos]; del nxt[middle]; nxt[landing] = piece

            if crown:

            else:
                extend(nxt, landing, piece, path+[landing], taken+[middle])
    for pos,piece in sorted(board.items()):
        if piece.lower() == side:
            extend(board, pos, piece, [pos], [])
    if captures:
        return captures
    moves = []
    for pos,piece in sorted(board.items()):
        if piece.lower() != side:
            continue
        for dr,dc in checker_directions(piece):
            to = (pos[0]+dr,pos[1]+dc)
            if 0 <= to[0] < 8 and 0 <= to[1] < 8 and to not in board:
                moves.append({"path": [pos,to], "captured": [],
                              "promotes": piece.islower() and to[0] == (7 if side == "r" else 0)})
    return moves

def dependency_cycle(edges):
    adjacency = {}
    for e in edges:
        if e["predicate"] == "depends_on":
            adjacency.setdefault(e["subject"],[]).append(e["object"])
    visiting, done = set(), set()
    def visit(node):
        if node in visiting: return True
        if node in done: return False
        visiting.add(node)
        for child in adjacency.get(node,[]):
            if visit(child): return True
        visiting.remove(node); done.add(node)
        return False
    return any(visit(node) for node in list(adjacency))

def compile_graph(proposals):
    accepted, rejected = [], []
    for edge in proposals:
        reason = None
        if edge.get("predicate") not in {"depends_on","reduces_latency_vs"}:
            reason = "unsupported_relation"
        elif not edge.get("source_sha256"):
            reason = "missing_provenance"
        elif edge["subject"] == edge["object"]:
            reason = "self_edge_disallowed_by_this_schema"
        elif dependency_cycle(accepted+[edge]):
            reason = "dependency_cycle"
        (rejected if reason else accepted).append({**edge, "rejection":reason} if reason else edge)
    return accepted, rejected

def pack_questions(state, questions, byte_budget=1300):
    packs, current = [], {}
    for key,q in questions.items():
        proposed = {**current,key:q}
        size = len(canonical({"state":state,"questions":proposed}).encode())
        if size > byte_budget:
            if not current:
                raise ValueError("A single question exceeds the local byte budget.")
            packs.append(current); current = {key:q}
            if len(canonical({"state":state,"questions":current}).encode()) > byte_budget:
                raise ValueError("A single question exceeds the local byte budget.")
        else:
            current = proposed
    if current: packs.append(current)
    return packs

def append_event(chain, kind, payload):

def verify_chain(chain, expected_final_hash):
    previous = "0"*64
    for index,event in enumerate(chain):
        unsigned = {k:v for k,v in event.items() if k != "sha256"}
        if event.get("index") != index or event.get("previous") != previous:
            return False
        if digest(unsigned) != event.get("sha256"):
            return False
        previous = event["sha256"]
    return previous == expected_final_hash

def binary_metrics(labels, probabilities):
    if len(labels) != len(probabilities) or not labels:
        raise ValueError("Nonempty aligned labels and probabilities are required.")
    if any(type(y) is not int or y not in (0,1) for y in labels):
        raise ValueError("Labels must be integer zero or one.")
    valid = [(y,p) for y,p in zip(labels,probabilities) if p is not None]
    if any(not probability(p) for _,p in valid):
        raise ValueError("Invalid probability.")
    if not valid:
        return {"total":len(labels),"valid":0,"unavailable":len(labels),"accuracy":None}
    confusion = {"tp":0,"tn":0,"fp":0,"fn":0}
    for y,p in valid:
        pred = int(p >= .5)
        confusion[{(1,1):"tp",(0,0):"tn",(0,1):"fp",(1,0):"fn"}[y,pred]] += 1
    tp,tn,fp,fn = (confusion[k] for k in ("tp","tn","fp","fn"))
    precision = tp/(tp+fp) if tp+fp else None
    recall = tp/(tp+fn) if tp+fn else None
    f1 = 2*tp/(2*tp+fp+fn) if 2*tp+fp+fn else None
    eps = 1e-12
    return {"total":len(labels),"valid":len(valid),"unavailable":len(labels)-len(valid),
       "confusion":confusion,"accuracy":(tp+tn)/len(valid),"precision":precision,"recall":recall,"f1":f1,
       "brier":sum((p-y)**2 for y,p in valid)/len(valid),
       "log_loss":-sum(y*math.log(max(eps,p))+(1-y)*math.log(max(eps,1-p)) for y,p in valid)/len(valid)}

def risk_coverage(labels,probs,threshold):
    if not .5 <= threshold <= 1: raise ValueError("Threshold outside [0.5,1].")
    selected = [(y,p) for y,p in zip(labels,probs) if p is not None and max(p,1-p)>=threshold]
    errors = sum(int(p>=.5)!=y for y,p in selected)
    return {"threshold":threshold,"accepted":len(selected),"errors":errors,
            "coverage_of_all_cases":len(selected)/len(labels),
            "selective_risk":errors/len(selected) if selected else None}

41. Metamorphic and counterfactual robustness tests¶

Level 5 · New extension

You will learn: Test what should stay invariant and what should change under controlled edits.

Label-preserving rewrites should usually preserve a decision; changed facts may require a changed decision. Both are useful tests. The cases below separate an untrusted instruction appended to a report from a factual change about whether a workaround works. Expectations are hand-labeled, not obtained from a second model vote. Failure indicates a test finding, not a reason to silently edit the expected answer. Passing these three cases is not a security proof.

42. Capstone: an auditable incident copilot¶

Level 6 · New synthesis of the earlier examples

You will learn: Connect state, candidate retrieval, semantic judgment, deterministic policy, and a review receipt.

This capstone uses a fictional incident and an in-memory runbook store. Stage one routes the incident. Code retrieves a bounded runbook candidate. Stage two evaluates relevance and checks whether more detail is needed. Code then creates a read-only evidence packet or an abstention. Every proposed operational action requires human/host authorization; this notebook neither changes a service nor closes a ticket.

Notice the division of labor: code supplies text templates, provenance, known permissions, and a repeatable plan. JEV answers questions. No free-form JEV plan generation is assumed.
