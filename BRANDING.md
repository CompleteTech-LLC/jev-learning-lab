Branding was applied at the owner's request. This package uses the original CompleteTech
cloud/lightbulb logo and the existing “Innovation at Every Integration” tagline.
The original JPEG is preserved and embedded in the notebook for portability.
The shared palette is recorded in `assets/brand-profile.json`; CSS is in
`assets/notebook-theme.css`. Brand metadata is not a general license to reuse the logo.

The notebook uses system sans-serif fonts and navy/blue headings, table headers, callouts,
and a connection-setup card. CSS improves appearance where the viewer supports it; the
embedded header has inline styling so the identity does not depend on executing CSS.
